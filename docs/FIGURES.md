# Figure captions

Every figure in this package is generated by script from logged data. Each entry below states what the figure shows, the n behind it, the data file and script that produced it, and its provenance label: **SCHEMATIC** (a drawing), **LOGGED-DATA RENDER** (plotted from recorded measurements) or **WEBOTS CAPTURE** (real rendered frames).

## F1 — Distribution-shift ladder L00–L05

The six layouts at identical metric scale. Grey fill is the configuration space a 0.18 m disc may not enter; the dashed red line is the A* reference route; the dashed orange rectangle is the cart's swept lane. Dissimilarity to L00 (1 − IoU of the static footprint rasters), en-route corridor width and A* length are printed under each panel. L02 is an exact reflection of L00: maximally dissimilar, identical difficulty.

- **n:** 6 layouts
- **data:** `07_SCENARIOS/L0*_C.json, 06_DATA/scenario_table.csv`
- **script:** `scripts/make_figures.py`
- **provenance:** LOGGED-DATA RENDER
- **files:** `assets/figures/F1_shift_ladder.png`, `assets/figures/F1_shift_ladder.pdf`, `assets/figures/F1_shift_ladder.svg`
