# `evidence/` — Traceability

**What is in here.** `CLAIMS_EVIDENCE.csv` maps every claim to its data file and script; `BASELINE_HASHES.txt` and `ENVIRONMENT.txt` pin what was frozen and on what machine; `RELEASE_STATE.md` is the working state; `FILE_MAP.md` records the v2 migration.

**How it is produced.** `scripts/make_claims.py` and `scripts/freeze.py`.
